# Предсказание стоимости аренды жилья по объявлению
Задача — регрессия
Предсказать месячную арендную плату по характеристикам объявления (площадь, комнаты, география, удобства, текст)

---

## Данные

[Apartment for Rent Classified](https://archive.ics.uci.edu/dataset/555/apartment+for+rent+classified) —
UCI Machine Learning Repository

| | |
|---|---|
| Объявлений | 99 492 (после очистки — 99 025) |
| Колонок | 22 (21 признак + таргет `price`) |
| Период | декабрь 2018 — декабрь 2019 |
| География | США, 51 штат, 2 979 городов |
| Таргет | `price` — месячная арендная плата, $ |

Данные в репозиторий не коммитятся `src/data/load.py` скачивает и распаковывает
их с UCI автоматически.

**Метрика качества — MAE в долларах** Она интерпретируется одной фразой («модель ошибается
в среднем на N долларов в месяц») и устойчива к выбросам, которых в ценах аренды много.
Дополнительно считаем RMSE, MAPE и R²

## Быстрый старт

```bash
make install       # окружение и зависимости
make data          # скачать и распаковать датасет
make baseline      # baseline
make experiments   # все эксперименты
make test          # тесты
make lint          # линтер
```

Запуск сервиса:

```bash
make reference     # справочник городов для API (один раз)
make api           # FastAPI на localhost:8000/docs
make ui            # Streamlit на localhost:8501
```

Через Docker

```bash
docker compose run --rm prepare-data   # подготовка данных
docker compose run --rm experiments    # эксперименты
docker compose up api ui               # сервис целиком
```

Без `make`:

```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/python -m src.data.load
.venv/bin/python -m src.models.baseline
```

Ноутбуки запускаются из папки `notebooks/` по порядку

## Запуск сервиса

### 1. Подготовка (один раз)

```bash
make install       # окружение и зависимости
make data          # скачать датасет с UCI
make baseline      # подготовить data/processed/dataset.parquet
make final         # обучить модель models/final_model.pkl
make reference     # справочник городов models/city_reference.json
```

Модель и справочник в git не хранятся, поэтому после свежего клона эти шаги
обязательны: без них API не стартует.

### 2. Запуск

Локально, в двух терминалах:

```bash
make api           # FastAPI: http://localhost:8000/docs
```

```bash
make ui            # Streamlit: http://localhost:8501
```

Или в контейнерах одной командой:

```bash
docker compose up api ui
```

Остановить контейнеры: `docker compose down`

**Финальная модель** XGBoost с подобранными через Optuna гиперпараметрами,
признаки: таблица + target encoding города + 100 компонент текста,
обучение на log(price). Обучена на train+val, оценена на нетронутом тесте

| Метрика | Валидация | Тест |
|---|---|---|
| MAE | 161.0 $ | 160.2 $ |
| RMSE | — | 300.6 $ |
| MAPE | — | 10.3 % |
| R² | — | 0.850 |

Выбрана по трём измеренным причинам: лучший MAE среди всех проверенных
моделей, лучшие RMSE и R² (реже допускает крупные промахи), обучение за
18 секунд против 49 у ближайшего конкурента.

**Интерпретируемость** Вклад групп признаков: категориальные 30.1%,
числовые характеристики 27.8%, город и штат 19.3%, текст 15.5%,
удобства 6.8%. В топе — город, число санузлов, штат, площадь

**Воспроизводимость**

- Единый `SEED = 42`, фиксируется через `src/utils/seed.py`
- Версии зависимостей зафиксированы в `requirements.txt`
- Линтер и форматтер ruff, `make lint` проходит без замечаний
- Данные скачиваются кодом, а не руками: прогон повторяется с нуля одной командой
- 19 тестов на подготовку данных и метрики, `make test` проходит
- Docker и docker-compose: прогон воспроизводится без установки Python на машину
- Результаты всех прогонов сохраняются в `experiments/runs/*.json` — цифры
  в отчёт попадают из файлов, а не переписываются руками
