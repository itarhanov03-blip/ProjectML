# Предсказание стоимости аренды жилья по объявлению
Задача — регрессия
Предсказать месячную арендную плату по характеристикам объявления (площадь, комнаты, география, удобства, текст)

---

## Данные

[Apartment for Rent Classified](https://archive.ics.uci.edu/dataset/555/apartment+for+rent+classified) —
UCI Machine Learning Repository

| | |
|---|---|
| Объявлений | 99 492 (после очистки — 99 025) |
| Колонок | 22 (21 признак + таргет `price`) |
| Период | декабрь 2018 — декабрь 2019 |
| География | США, 51 штат, 2 979 городов |
| Таргет | `price` — месячная арендная плата, $ |

Данные в репозиторий не коммитятся `src/data/load.py` скачивает и распаковывает
их с UCI автоматически.

**Метрика качества — MAE в долларах.** Она интерпретируется одной фразой («модель ошибается
в среднем на N долларов в месяц») и устойчива к выбросам, которых в ценах аренды много.
Дополнительно считаем RMSE, MAPE и R²

## Быстрый старт

```bash
make install     # окружение и зависимости
make data        # скачать и распаковать датасет (~100 МБ)
make baseline    # прогнать весь пайплайн и получить метрики
```

Без `make`:

```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/python -m src.data.load
.venv/bin/python -m src.models.baseline
```

Ноутбуки запускаются из папки `notebooks/` по порядку

**Обработка и подготовка данных**

- Разобраны пропуски `address` (92%) удалена, мультиселекты `amenities` и `pets_allowed`
  заполнены как «не указано», строки без гео и таргета удалены, комнаты заполнены медианой
- Найдены 84 полных дубля и повторные подачи одного объекта (около трети строк)
- Обнаружены 4 объявления с недельной ценой — пересчитаны в месячную
- Выбросы отсечены по осмысленным границам (200–10 000 $), а не по IQR: распределение
  скошено вправо, и симметричные правила отрезали бы реальные дорогие квартиры
- Сгенерировано 55 числовых признаков вместо 5 исходных: 27 флагов удобств, флаги питомцев,
  статистики текста, производные от площади и комнат, гео- и временные признаки
- Колонка `price_display` (цена строкой — даёт R2 = 0.999) и упоминания цены в тексте объявления
- Объявления об одном объекте целиком уходят в одну выборку. Наивный случайный сплит завышал качество на 7%. `check_leakage` возвращает нули
